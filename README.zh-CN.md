# EPUB Reader and Highlighter

[English](README.md) | 简体中文 | [繁體中文](README.zh-TW.md) | [Italiano](README.it.md)

在 Obsidian 里直接阅读 EPUB 电子书,用多色高亮和笔记做标记,并把所有内容导出为 Markdown。

## 功能

- **内置 EPUB 阅读器** — 打开库中任意 `.epub` 文件,不离开 Obsidian 就能阅读。
- **滚动 / 分页模式** — 在连续滚动和逐页阅读之间切换;用屏幕上的按钮或 ← / → 方向键翻页。
- **固定页码(Apple Books 方式)** — 后台按当前窗口大小和字体预排全书,阅读过程中总页数固定不变,每翻一页页码只 +1。首次打开会短暂显示"计算中";结果会缓存,只在窗口或字体变化时重算。在页码框输入数字可直接跳到那一页;滚动模式下则显示阅读进度百分比。
- **记住阅读位置** — 关闭书籍(或退出 Obsidian)后重新打开,自动回到上次读到的段落。
- **多色高亮** — 选中文字后在弹出色板中选色,或按 **`Cmd/Ctrl+Shift+H`** 用默认颜色高亮;默认颜色跨会话记忆。
- **高亮笔记** — 给任意高亮附加批注。
- **相邻高亮自动合并** — 紧接着已有高亮往后划，两条合并为一条；中间隔了空白和标点以外的内容则仍是两条。
- **高亮菜单** — 点击一条高亮，就地换颜色（预设色、这本书用过的自定义色，或取色轮）、写备注、复制或删除。
- **批注存放在你的库里** — 每本书的高亮是你指定文件夹里的一个文件，任何同步工具都会带上，改动一本书只传输那一个文件。
- **高亮面板** — 查看当前书籍的全部高亮,含页码、原文和笔记;可跳回原文位置、编辑笔记或删除。
- **复制为引用** — 把当前选中文字或全部高亮一键复制成 `*页码 · 时间*` + 引用块,直接粘贴进笔记。
- **撤销** — `Cmd/Ctrl+Z` 撤销最近一次高亮或删除。
- **阅读主题** — 五种内置背景色,外加内嵌取色面板(无系统弹窗)自定义任意颜色;字体、字号可调;链接颜色随背景自动适配保证可读性。
- **全书搜索** — 在整本书中搜索关键词,点击结果跳转。
- **跨页高亮** — 标记起点后可以任意翻页，再从后面的选区结束，一次性高亮整段（限同一章内）。
- **最近使用的颜色** — 用过的自定义色随手可取；当没有高亮再用它时自动从列表消失。
- **导出全书正文** — 把整本书导出为一个文件，或按章节分别导出并生成索引双链。已划线的段落可选择用 `==` 标出。
- **Markdown 导出** — 导出全部或选中的高亮，可指定文件夹、分组方式、排序方式以及每条高亮要带哪些信息。每次导出都是一个带日期时间的新文件，永不覆盖旧文件。
- **合并导出的笔记** — 把同一本书的多份导出合成一份：重复内容自动去除，你自己写的内容原样保留，原文件不会被修改。
- **高亮快捷键可自定义** — 默认 `Cmd/Ctrl+Shift+H`，可在插件设置里改成任意组合。
- **自定义导出模板** — 用 `{{text}}`、`{{note}}`、`{{page}}`、`{{chapter}}` 等变量决定每条高亮怎么写，并支持「有备注才输出」的条件块。
- **首次使用引导** — 首次打开弹出一次性的工具栏图标说明;同样的内容也保留在插件设置页里。

## 批注存放在哪里

每本书的高亮是库里的一个 `.json` 文件，位置由插件设置中的**批注存储**决定（默认 `epub-highlights`）。因为它们是普通的库内文件，你原本用的同步方式——Obsidian Sync、remotely-save、git——都会带上它们，改动一本书也只传输那一本的文件。换文件夹时既有文件会一起搬过去。

Obsidian 的文件列表不显示 `.json`，所以这个文件夹在侧边栏看起来是空的，文件确实在。用访达打开库文件夹，或打开**选项 → 文件与链接 → 检测所有文件扩展名**。

每条高亮同时用 CFI 和它在章节文字中的位置定位。如果周围的标记结构发生变化——换了台机器、相邻的高亮被删除——文字定位会重新找到这段话并修复 CFI。如果某个路径下的 epub 被换成了另一个文件，它的批注会被保留在一个标记为旧版的文件里，而不是画在对不上的新书上。

## 安装

### 从社区商店安装
在 **设置 → 第三方插件 → 浏览** 中搜索 "EPUB Reader and Highlighter",安装并启用。

### 手动安装
1. 从最新 [release](https://github.com/okkio-31mon/epub-reader-highlighter/releases) 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 复制到 `<你的库>/.obsidian/plugins/epub-reader-highlighter/`。
3. 重载 Obsidian,并在 **设置 → 第三方插件** 中启用。

## 使用

1. 把 `.epub` 文件放到库中任意位置,点击即可打开。
2. 选中文字进行高亮 — 在弹出色板中点选颜色,或按 `Cmd/Ctrl+Shift+H` 使用默认颜色。
3. 点击已有高亮可添加或编辑笔记。
4. 通过工具栏浏览目录、复制引用、打开高亮菜单、调整字体和背景、翻页、搜索全书。

### 工具栏图标

| 图标 | 作用 |
| --- | --- |
| ☰(菜单) | **目录** — 查看章节目录,点击跳转。 |
| 〝(引用) | **复制引用** — 把选中文字复制成 `*页码 · 时间*` + 引用块。 |
| ▮(荧光笔) | **高亮菜单** — 打开高亮列表、复制全部、导出(全部或所选)、设置默认高光颜色。 |
| ≡(滑杆) | **阅读设置** — 字体、字号、背景色;点色轮展开取色面板自定义任意颜色。 |
| 滚动 / 分页 | 在连续滚动和逐页阅读之间切换。 |
| ‹ 页码 › | 上一页 / 下一页(← / → 也可以)。页码框显示固定页码 / 总页数 · 百分比 — 输入数字回车可跳页;滚动模式下显示进度百分比。 |
| 🔍 | **搜索** — 在全书中搜索关键词并跳转到结果。 |
| ✎（铅笔） | **跨页高亮 · 起点** — 标记一段话的开头，然后翻页。 |
| ✎✓（铅笔加勾） | **跨页高亮 · 结束** — 把标记的起点到当前选区之间全部高亮。 |
| ⋯ | **更多** — 界面语言和使用说明。 |

点击已有的高亮会弹出操作栏：更换颜色、写备注、复制、删除。

快捷键:`Cmd/Ctrl+Shift+H` 高亮选中文字（组合可在插件设置里修改） · `Cmd/Ctrl+Z` 撤销。

高亮以每本书一个文件的形式存在库里（见[批注存放在哪里](#批注存放在哪里)），阅读位置和偏好设置存在插件自己的数据文件中。都不会离开你的设备。

## 导出与合并

在高亮菜单里选 **高光内容选择导出…**。弹窗上排决定*导出哪些*：「全部」「今日」「章节选择」，以及这本书用到的每种颜色的色点（色点的选择按书记住）。下排是*这一次*的设置：排序方式、目标文件夹，以及一个「设为默认」勾选框——勾了才写回设置。

同一菜单里的 **导出为 Markdown** 不经过弹窗，直接导出全部。

插件设置里存的是默认值：导出文件夹、分组方式（不分组 / 按章节 / 按颜色）、排序方式（按书中顺序或按划线时间），以及章节、页码、日期、备注、颜色名称和序号的开关。

打开 **使用自定义模板** 后，这些开关会换成一个模板框，由你决定每条的排版：`{{index}}`、`{{text}}`、`{{note}}`、`{{page}}`、`{{chapter}}`、`{{book}}`、`{{date}}`、`{{time}}`、`{{color}}`。`{{#note}}` 和 `{{/note}}` 之间的内容只在有备注时才输出，没备注的条目不会留下空标签。分组标题和每条之间的分隔线仍由插件输出——合并功能依赖它们。

同一本书产出的所有文件——高亮摘录、合并摘录、正文——都归档在以书名命名的文件夹里，位于你设定的导出文件夹下：

```
导出文件夹/
└── 书名/
    ├── 高亮摘录 2026-08-27-1430.md
    ├── 正文 2026-08-27-1629.md
    └── 章节选择 2026-08-27-1640/
        ├── 索引.md
        └── 第 1 章….md
```

因为每次导出都是独立的带时间戳文件，一本书分几次读完就会留下几份笔记。**合并已导出的高亮摘录**（命令面板，或设置里的按钮）可以把其中任意几份合成一份：选择文件、分组和排序，预览结果，然后写入一个新文件。重复的高亮只保留一条；对应不上任何高亮的内容——你自己写的，或被你改动过的原文——保留在「其他内容」里。原文件始终不会被修改。

## 导出全书正文

高亮菜单里还有 **导出全书正文…**。两种布局任选：

- **整本一个文件** — 章节以 `##` 标题排在同一个文件里。
- **一章一个文件** — 每章一个文件，另加一个按阅读顺序链接各章的索引文件。

勾选要导出的章节；封面、版权页、书自带的目录页也会列出来，通常可以不勾。图片会略过，书内链接只保留文字。

**标注已高亮的内容**会把你划过线的段落用 `==` 包起来。颜色不会带过来——颜色保留在高亮摘录里。导出后会提示匹配到多少条；措辞已经和转换后的正文对不上的高亮会被跳过，不会静默丢失。
