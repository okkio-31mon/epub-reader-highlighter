# EPUB Reader and Highlighter

[English](README.md) | [简体中文](README.zh-CN.md) | 繁體中文 | [Italiano](README.it.md)

在 Obsidian 裡直接閱讀 EPUB 電子書,用多色高亮和筆記做標記,並把所有內容匯出為 Markdown。

## 功能

- **內建 EPUB 閱讀器** — 開啟儲存庫中任意 `.epub` 檔案,不離開 Obsidian 就能閱讀。
- **捲動 / 分頁模式** — 在連續捲動和逐頁閱讀之間切換;用畫面上的按鈕或 ← / → 方向鍵翻頁。
- **固定頁碼(Apple Books 方式)** — 背景按目前視窗大小和字型預排全書,閱讀過程中總頁數固定不變,每翻一頁頁碼只 +1。首次開啟會短暫顯示「計算中」;結果會快取,只在視窗或字型變化時重算。在頁碼框輸入數字可直接跳到那一頁;捲動模式下則顯示閱讀進度百分比。
- **記住閱讀位置** — 關閉書籍(或退出 Obsidian)後重新開啟,自動回到上次讀到的段落。
- **多色高亮** — 選取文字後在彈出色板中選色,或按 **`Cmd/Ctrl+Shift+H`** 用預設顏色高亮;預設顏色跨工作階段記憶。
- **高亮筆記** — 給任意高亮附加批註。
- **高亮面板** — 檢視目前書籍的全部高亮,含頁碼、原文和筆記;可跳回原文位置、編輯筆記或刪除。
- **複製為引用** — 把目前選取文字或全部高亮一鍵複製成 `*頁碼 · 時間*` + 引用區塊,直接貼進筆記。
- **復原** — `Cmd/Ctrl+Z` 復原最近一次高亮或刪除。
- **閱讀主題** — 五種內建背景色,外加內嵌取色面板(無系統彈窗)自訂任意顏色;字型、字級可調;連結顏色隨背景自動適配確保可讀性。
- **全書搜尋** — 在整本書中搜尋關鍵詞,點擊結果跳轉。
- **Markdown 匯出** — 從高亮選單把全部高亮或選取的部分匯出為 Markdown 筆記。
- **首次使用引導** — 首次開啟彈出一次性的工具列圖示說明;同樣的內容也保留在外掛設定頁裡。

## 安裝

### 從社群商店安裝
在 **設定 → 第三方外掛 → 瀏覽** 中搜尋 "EPUB Reader and Highlighter",安裝並啟用。

### 手動安裝
1. 從最新 [release](https://github.com/okkio-31mon/epub-reader-highlighter/releases) 下載 `main.js`、`manifest.json` 和 `styles.css`。
2. 複製到 `<你的儲存庫>/.obsidian/plugins/epub-reader-highlighter/`。
3. 重新載入 Obsidian,並在 **設定 → 第三方外掛** 中啟用。

## 使用

1. 把 `.epub` 檔案放到儲存庫中任意位置,點擊即可開啟。
2. 選取文字進行高亮 — 在彈出色板中點選顏色,或按 `Cmd/Ctrl+Shift+H` 使用預設顏色。
3. 點擊已有高亮可新增或編輯筆記。
4. 透過工具列瀏覽目錄、複製引用、開啟高亮選單、調整字型和背景、翻頁、搜尋全書。

### 工具列圖示

| 圖示 | 作用 |
| --- | --- |
| ☰(選單) | **目錄** — 檢視章節目錄,點擊跳轉。 |
| 〝(引用) | **複製引用** — 把選取文字複製成 `*頁碼 · 時間*` + 引用區塊。 |
| ▮(螢光筆) | **高亮選單** — 開啟高亮清單、複製全部、匯出(全部或所選)、設定預設高光顏色。 |
| ≡(滑桿) | **閱讀設定** — 字型、字級、背景色;點色輪展開取色面板自訂任意顏色。 |
| 捲動 / 分頁 | 在連續捲動和逐頁閱讀之間切換。 |
| ‹ 頁碼 › | 上一頁 / 下一頁(← / → 也可以)。頁碼框顯示固定頁碼 / 總頁數 · 百分比 — 輸入數字按 Enter 可跳頁;捲動模式下顯示進度百分比。 |
| 🔍 | **搜尋** — 在全書中搜尋關鍵詞並跳轉到結果。 |
| ⋯ | **更多** — 介面語言和使用說明。 |

快捷鍵:`Cmd/Ctrl+Shift+H` 高亮選取文字 · `Cmd/Ctrl+Z` 復原。

高亮、閱讀位置和偏好設定都儲存在儲存庫內本外掛的 `data.json` 中,不會離開你的裝置。

## 開發

```bash
npm install
npm run dev    # 監看建置
npm run build  # 正式建置
```

## 致謝

EPUB 渲染基於 [epub.js](https://github.com/futurepress/epub.js)。
